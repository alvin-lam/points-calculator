# Airline logos

Single-color SVG logos for 28 airlines in the calculator, from [Simple Icons](https://simpleicons.org) version 16.38.1. Simple Icons releases its icon files under CC0 1.0 (public domain); see `LICENSE.md`.

The logos are trademarks of their airlines. CC0 covers the files, not the trademarks. Use them only to identify each airline, and never in a way that suggests the airline endorses or sponsors this site.

- `index.json` maps each calculator menu value (for example `united` or `milesandmore:lh`) to its file, the airline's name, its brand color in Simple Icons, and the source Simple Icons used.
- The files have no color set, so they draw in black by default. Set `fill` (or use them as a CSS mask) to color them.
- Not available from Simple Icons: the alliance logos (oneworld, Star Alliance, SkyTeam) and the other 45 airlines. Add them from each owner's media or press center, with its usage terms, if needed.

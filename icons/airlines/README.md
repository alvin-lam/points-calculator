# Airline and alliance logos

Logos for 61 airlines and 1 alliance in the calculator. `index.json` maps each calculator menu value (for example `united`, `milesandmore:lh` or `alliance:oneworld`) to its file, name, source and license.

## Sources

1. **Simple Icons** (28 single-color SVGs): from [Simple Icons](https://simpleicons.org) version 16.38.1, released under CC0 1.0 (see `LICENSE.md`). They have no color set; give them a `fill` or use them as a CSS mask.
2. **The airline's own website** (2 PNGs): Hong Kong Airlines and Frontier. The Frontier file is the white version, for dark backgrounds.
3. **Wikimedia Commons** (32 SVGs): each file page and license is listed in `index.json`. All of these are marked public domain on Commons, usually because a simple text or shape logo is not eligible for copyright.

## Trademarks

Every logo is a trademark of its airline or alliance. The licenses above cover copyright in the files, not the trademarks. Use the logos only to identify each airline, and never in a way that suggests the airline or alliance endorses or sponsors this site.
